# Scenario de test : controle souris complet
# Commande system;mousecontrol;True/False
#
# Structure :
#   Phase 1 (0:00 - 1:00) : Mouse control ON — tester le clic sur les 4 plugins
#   Phase 2 (1:00 - 1:30) : Mouse control OFF — verifier que les clics n'ont plus d'effet
#   Phase 3 (1:30 - 2:30) : Mouse control ON a nouveau — tester la reactivation
#
# Instructions de test manuel :
#   - Le curseur souris doit devenir visible des 0:00:00
#   - Sysmon : cliquer sur les jauges/lumieres quand elles sont en failure
#   - Resman : cliquer sur les triangles des pompes pour les activer/desactiver
#   - Communications : cliquer sur une radio pour la selectionner, puis
#       zone gauche (<25%) = baisser frequence
#       zone droite (>75%) = monter frequence
#       zone centrale (25%-75%) = valider la reponse
#   - Track : cliquer-glisser dans le reticule pour compenser le curseur
#   - A 1:00, le mousecontrol est desactive — les clics ne font plus rien
#   - A 1:30, le mousecontrol est reactive

# ──────────────────────────────────────────────
# 0. Demarrage des plugins + activation souris
# ──────────────────────────────────────────────
0:00:00;sysmon;start
0:00:00;track;start
0:00:00;resman;start
0:00:00;communications;start
0:00:00;system;mousecontrol;True

# ──────────────────────────────────────────────
# Phase 1 : Mouse control ON (0:00 - 1:00)
# ──────────────────────────────────────────────

# Sysmon : declenchement de failures pour tester les clics
0:00:05;sysmon;scales-1-failure;True
0:00:15;sysmon;lights-2-failure;True
0:00:25;sysmon;scales-3-failure;True
0:00:35;sysmon;lights-1-failure;True
0:00:45;sysmon;scales-2-failure;True

# Communications : prompts pour tester navigation + tuning + validation
0:00:05;communications;radioprompt;own
0:00:30;communications;radioprompt;own

# Resman : mettre quelques pompes en panne puis les reparer
# pour forcer l'utilisateur a activer d'autres pompes
0:00:10;resman;pump-2-state;failure
0:00:30;resman;pump-2-state;off
0:00:40;resman;pump-5-state;failure
0:00:55;resman;pump-5-state;off

# Track : le curseur derive naturellement, l'utilisateur compense par drag

# ──────────────────────────────────────────────
# Phase 2 : Mouse control OFF (1:00 - 1:30)
# Les clics ne doivent plus avoir d'effet
# ──────────────────────────────────────────────
0:01:00;system;mousecontrol;False

# Failures continuent — seul le clavier fonctionne
0:01:05;sysmon;scales-4-failure;True
0:01:10;communications;radioprompt;own

# ──────────────────────────────────────────────
# Phase 3 : Mouse control ON a nouveau (1:30 - 2:30)
# Verifier que la reactivation fonctionne
# ──────────────────────────────────────────────
0:01:30;system;mousecontrol;True

0:01:35;sysmon;scales-1-failure;True
0:01:35;sysmon;lights-2-failure;True
0:01:45;communications;radioprompt;own
0:02:00;sysmon;scales-2-failure;True
0:02:00;communications;radioprompt;own
0:02:10;resman;pump-3-state;failure
0:02:20;resman;pump-3-state;off

# ──────────────────────────────────────────────
# Arret de tous les plugins a 2:30
# ──────────────────────────────────────────────
0:02:30;sysmon;stop
0:02:30;track;stop
0:02:30;resman;stop
0:02:30;communications;stop
